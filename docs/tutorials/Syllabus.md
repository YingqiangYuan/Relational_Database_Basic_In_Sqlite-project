# Syllabus

This course teaches a six-move playbook for absorbing any small learning repo: **absorb, quiz, elevate, interview, demo, publish** — six Claude Code skills that turn a small worked example into a fully understood, defensible, presentable artifact, then ship a clean portfolio version to your own GitHub. Each module applies the playbook to a different tech topic. You leave with a methodology that transfers to every future small repo you'll ever encounter.

## 01-Introduction-to-Relational-Database

First worked example: relational databases. The repo holds ten SQLite + SQLAlchemy 2.0 scripts in two parallel series — `s1x` teaches CRUD as raw SQL via `text(...)`, `s2x` teaches the same CRUD via Core Expression. You run all six skills end-to-end: absorb each script, quiz to the 3-part standard (where + what + why), elevate toward tests / ORM / JOINs, mock-interview with pushback, build a demo, then publish a clean portfolio version. After this module you can defend the repo to a stranger and reuse the playbook on any future small repo.
