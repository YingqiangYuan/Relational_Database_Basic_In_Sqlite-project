# Syllabus

This course teaches a five-move playbook for absorbing any small learning repo: **absorb, elevate, quiz, interview, demo** — five Claude Code skills that turn a small worked example into a fully understood, defensible, presentable artifact. Each module applies the playbook to a different tech topic. You leave with a methodology that transfers to every future small repo you'll ever encounter.

## 01-Introduction-to-Relational-Database

First worked example: relational databases. The repo holds five SQLAlchemy 2.0 Core + SQLite scripts covering CREATE / INSERT / SELECT / UPDATE / DELETE. You run all five skills end-to-end: absorb each script, quiz to 80%+, elevate toward tests / ORM / multi-table, mock-interview, then build a demo script. After this module you can defend this repo on a résumé and apply the same playbook to any future small repo.
