# learn_relational_database_basic_in_sqlite-project

This project looks like a SQL relational database tutorial, but its real product is a six-move methodology — absorb, quiz, elevate, interview, demo, publish — for mastering any small learning repo. SQLAlchemy 2.0 Core + SQLite is just the vehicle, kept deliberately small so the method dominates the content. You run the full `/learn-this-project-*` skill set end-to-end on this repo, then reuse the same playbook on every future skill-sized project. The takeaway is the muscle memory, not the SQL.
